## Accessibility & Keyboard

### Semantic & WCAG Contract

- Render `role="tablist"` with an accessible `label`; native `focusgroup="tablist"` provides one tab stop and arrow keys where supported.
- Consumers render `role="tab"` buttons with `aria-selected`, and `role="tabpanel"` elements with `aria-labelledby`; all panels except the selected one must start `hidden`.
- Selection is styled from `aria-selected`, never a separate class.

### Keyboard Interactions

- `Arrow` keys move between tabs (native focusgroup, or the Part 9.1 fallback); `Home`/`End` jump to first/last.
- `Enter`/`Space` selects the focused tab; automatic activation also selects on arrow movement.
