## Accessibility & Keyboard

### Semantic & WCAG Contract

- Renders a native `[popover]` element; top-layer promotion, light dismiss and Escape come from the platform.
- Does not invent roles: add `role="menu"` / `role="listbox"` on the host when implementing those patterns.
- Use either `popovertarget` or `command="toggle-popover"` on the trigger, never both for the same popover.

### Keyboard Interactions

- `Escape` / light dismiss: closes per the native `popover` value.
- With `trigger` set, hiding the popover from a button inside it returns focus to the trigger.
