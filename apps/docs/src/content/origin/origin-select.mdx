## Accessibility & Keyboard

### Semantic & WCAG Contract

- Renders a real `<label for>` before the `<select>`; the label is required at compile time.
- Hints are persistent text linked with `aria-describedby`, never placeholder-only instructions.
- The native select owns keyboard behavior, form submission and accessible roles.

### Keyboard Interactions

- Native select keyboard interaction (Arrow keys, Home/End, typeahead, Enter/Space).
