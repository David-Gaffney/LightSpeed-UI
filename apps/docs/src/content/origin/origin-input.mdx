## Accessibility & Keyboard

### Semantic & WCAG Contract

- Renders `<label for>` before the input; a visible label is mandatory.
- Helper text is persistent and linked via `aria-describedby`; `placeholder` is never used as the only instruction.
- Required fields are marked both visually (via the label text) and with the native `required` attribute.

### Keyboard Interactions

- Native input keyboard behavior; `enterkeyhint` and `autocomplete` are passed through.
