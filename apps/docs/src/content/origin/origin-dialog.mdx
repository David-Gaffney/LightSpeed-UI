## Accessibility & Keyboard

### Semantic & WCAG Contract

- Renders a native `<dialog>` opened only with `command="show-modal"` / `showModal()`.
- No `role="dialog"`, `aria-modal`, manual focus trap, `inert` toggling or Escape handler: the native modal already provides all of them.
- Consumers supply an accessible name via `labelledBy` (or `aria-labelledby`) and may add `describedBy`.

### Keyboard Interactions

- `Escape` / back gesture: closes the native modal; focus returns to the invoker automatically.
- `command="show-modal"` on the invoker opens it; `command="close"` in the content closes it.
