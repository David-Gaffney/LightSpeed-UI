**Apogee (`@lsui/apogee`)** is Level 4—an independent tier for richer, self-contained interactive capabilities and site enhancements that go beyond standard UI primitives, styled components, or static page blocks.

Read **[Core Goals of Apogee](/apogee/core-goals/)** for how Apogee stays modular and opt-in across any Astro site.
