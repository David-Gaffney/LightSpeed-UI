**LightSpeedUI (`lsui`)** is a complete **Astro UI Platform** organized into four clearly separated levels—from unstyled accessible primitives and headless behaviors up to themed copy-paste components, CMS page blocks, and independent interactive experiences.

## Four Platform Levels

Use the header tabs above—or jump directly to each level:

| Level | Package | Role & Goal |
| :--- | :--- | :--- |
| **1. [Origin](/origin/)** | `@lsui/origin` | Unstyled accessible `.astro` primitives, headless behaviors, keyboard interaction, `ariaNotify()` screen reader announcements, `aria-disabled` focus guards, and rendering flexibility. |
| **2. [Liftoff](/liftoff/)** | `@lsui/liftoff` + `@lsui/themes` | Copy-paste styled `.astro` components layered strictly atop **Origin**, introducing semantic CSS tokens (`@layer lsui`), **Nordic** & **Editorial** themes, and ambient `data-*` contexts. |
| **3. [Landing](/landing/)** | `@lsui/landing` | Composed page blocks, marketing/publishing/docs sections, and full-page templates layered strictly atop **Liftoff** for Astro and **EmDash CMS**. |
| **4. [Apogee](/apogee/)** | `@lsui/apogee` | Independent higher-order interactive experiences and site enhancements beyond standard UI kits (Guided Website Tours, Kanban boards, Spotlight centers). |

## Strict Layering Rule

Levels 1–3 enforce a strict one-way dependency chain (**`Origin ← Liftoff ← Landing`**)—lower levels never import from higher levels—while **Apogee** remains modular and independent so any Astro site can adopt higher-order features without lock-in.
