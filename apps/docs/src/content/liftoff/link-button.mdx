## Installation

```bash
npx lsui add link-button
```

## Props

| Prop | Type | Default | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `variant` | `"primary" \| "secondary" \| "outline" \| "ghost" \| "danger"` | `"primary"` | No | Visual style token variant matching Button. |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | No | Control height and padding scale. |
| `render` | `boolean` | — | No | Conditionally renders the component when `true` (omits markup when `false`). |
| `href` | `string \| URL` | — | Conditionally required by discriminated union | Destination URL navigated to on activation. |
| `disabled` | `boolean` | `false` | Required when disabled is true | Active link state (`false` by default). |
| `iconOnly` | `boolean` | `false` | Required when iconOnly is true |  |
| `aria-label` | `string` | — | Required when iconOnly is true | Screen-reader accessible name |

## Slots

| Slot | Description |
| :--- | :--- |
| `icon-start` | Optional leading decorative icon (`aria-hidden="true"` on SVGs). |
| `default` | Visible link label text. |
| `icon-end` | Optional trailing decorative icon (`aria-hidden="true"` on SVGs). |

## Accessibility & Keyboard

### Semantic & WCAG Contract

- Delegates native `<a>` link semantics and accessible `disabled` link handling (`role="link" aria-disabled="true"` without `href`) to `@lsui/origin` (`OriginLink`).
- Enforces >= 24x24px minimum target on desktop and >= 44x44px on coarse touch pointers (`--target-min-size`).
- Icon-only link buttons (`iconOnly`) require an explicit `aria-label` at compile time.

### Keyboard Interactions

- `Enter`: Follows the link `href` (blocked when `disabled` / `aria-disabled="true"`).
