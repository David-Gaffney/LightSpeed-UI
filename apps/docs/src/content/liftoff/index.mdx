**Liftoff (`@lsui/liftoff` + `@lsui/themes`)** is Level 2—where theming, semantic design tokens, and copy-paste styled `.astro` components are layered strictly on top of [Origin](/origin/) (comparable in role to **shadcn/ui**, built natively for Astro).

Read **[Core Goals of Liftoff](/liftoff/core-goals/)** for how Liftoff pairs open-code `.astro` ownership with `@layer lsui` semantic tokens and ambient `data-*` DOM contexts.

## Catalog

| Name | Category | Element | Hydration | Summary |
| :--- | :--- | :--- | :--- | :--- |
| [`Button`](/liftoff/button/) | Actions | `<button>` | `optional` | Themed, copy-paste action button built atop OriginButton. Adds semantic token variants, sizes, hover/press/focus states, and WCAG 2.5.8 / 2.5.5 minimum target sizing. For URL navigation, use LinkButton instead. |
| [`LinkButton`](/liftoff/link-button/) | Actions | `<a>` | `optional` | Themed navigation link built atop OriginLink. Applies Button visual variants and sizes to a genuine `<a>` element without ever overriding link semantics with `role="button"`. |
