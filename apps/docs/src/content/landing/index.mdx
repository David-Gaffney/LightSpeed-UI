**Landing (`@lsui/landing`)** is Level 3—composed real-world page sections, CMS blocks, and full-page templates built strictly on top of [Liftoff](/liftoff/) (comparable in role to **shadcnblocks**, built natively for standalone Astro and **EmDash CMS**).

Read **[Core Goals of Landing](/landing/core-goals/)** for how Landing composes Liftoff components across marketing, editorial, and documentation layouts.
