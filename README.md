# LightSpeedUI (`lsui`)

Astro-native UI platform combining open-code `.astro` components, composable `@lsui/behaviors` primitives, semantic CSS tokens (`@layer lsui`), Astro + EmDash CMS publishing primitives, automated Code-to-Figma sync, and 3-stage AST upgrades.

See `../PLAN.md` and `../FINDINGS.md` for the phased roadmap and engineering decisions log.
