# Changesets

LightSpeedUI (`@lsui/*`) uses Changesets with a **fixed lockstep version group**. Any release bump keeps `@lsui/behaviors`, `@lsui/core`, `@lsui/themes`, `@lsui/cli`, `@lsui/codemods`, and companion packages on one shared version number so component markup, headless behaviors, codemods, and the Figma Librarian stay in sync.
